Set up Dota Translator

Read your teammates’ chat in English and reply in their language. The current app includes hosted translation, so setup starts with your email, not an API key.

On this page Install and sign in Dota display mode Restart Dota once Incoming translations Translated replies Troubleshooting

Download and sign in

Install the current Dota Translator for Windows. The app includes hosted translation, so you do not need to create or paste a personal Gemini API key.

  1. Open Dota Translator. For translated Ctrl+Enter replies, right-click the app and choose Run as administrator so Windows can send the translated input to Dota.
  2. Enter your email address and request a sign-in email.
  3. Enter the six-digit code, or open the sign-in link while keeping the requesting app open.

Your first successful sign-in starts the 3-day trial. After the trial, access costs €7 for 3 months, paid when you choose to renew.

Use Borderless Window or Windowed mode

In Dota, open Settings → Video → Display Mode and choose Borderless Window or Windowed. The translation overlay is a separate window above the game's chat. Exclusive fullscreen can prevent that window from appearing over Dota.

This changes Dota's display mode. There is no need to lower your desktop screen resolution.

Restart Dota once after setup

Dota reads its Game State Integration chat-feed configuration when the game starts. After installing Translator, restart Dota once so that it can pick up the feed.

Leave Translator running while you play. It lives in the Windows system tray near the clock when its setup window is closed.

Read Russian, Spanish and Chinese chat in English

Incoming translations appear above Dota's own chat. The original game chat remains available. Dota Translator works from the game's chat feed, so it does not require you to copy every incoming message or take a screenshot yourself.

Only lines needing translation are sent through the hosted service. Repeated translations can be reused from a temporary cache, which avoids making the same translation request again. Names, game slang and short messages can still be ambiguous; use the original line for context.

Send a translated reply with Ctrl+Enter

Choose your outgoing language in Translator's settings. Type into Dota chat as usual, then press Ctrl+Enter when you want Translator to translate and send that reply. Plain Enter sends the text as you typed it.

For example, the website demo shows «иду топ, помогите» translated as “going top, help”. The shortcut acts only when you ask to send a reply while Dota is in front.

If the overlay or replies do not work

  • No incoming translations: check that you are signed in with active access, Dota has been restarted after setup, and your internet connection works.
  • The overlay is hidden: check Dota's display mode and whether the overlay was hidden with Alt+D. That shortcut can be changed in settings.
  • Ctrl+Enter does not send: check the outgoing-language setting and run Dota Translator as administrator, then try again with Dota in front.
  • Old API-key instructions: update the app. The current version uses hosted translation and email sign-in.

If a problem persists, email support@dotatranslator.live. Include the app version, what you expected and what happened. See the privacy details for how chat, account and usage information is handled.
